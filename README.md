O projeto foi estruturado focando em boas práticas de desenvolvimento mobile, incluindo design modular de componentes, gerenciamento otimizado de layout com StyleSheet, suporte a diferentes densidades de tela e feedback visual imersivo.
O app faz parte de um componente escolar desenvolvido em sala de aula.

---

## Tecnologias Utilizadas

- **[React Native](https://reactnative.dev/):** Framework para desenvolvimento de aplicações mobile multiplataforma.
- **[Expo](https://expo.dev/):** Plataforma para simplificação do fluxo de build e execução de aplicações React Native.
- **JavaScript (ES6+):** Linguagem principal de programação do projeto.
- **StyleSheet API:** Estilização nativa otimizada para alto desempenho.
